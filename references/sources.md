# 来源与证据

2026-10-25。由 benphant 与 Codex 根据用户反馈、制作复盘和公开方法重新组织编写。未打包第三方完整 Skill、受限专项资料或案例媒体。

用户运镜截图提供：摄影机信息动机、路径、呼吸感、固定光源、编号与距离、背景异步行为。原作者与原帖无法充分核验，本仓库不分发截图，不声称这些规则有平台实验证明。

项目复盘涉及旧帧污染、三视图异人、背面长正面结构、节点和提示词时长不一致、动作跳过及正文未实际绑定角色。修正方法可检验，但不保证所有模型稳定遵循。
