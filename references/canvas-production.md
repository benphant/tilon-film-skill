# 画布执行

这是制作层约定，不是 CLI 参数手册。优先使用可用的官方 dreamina-canvas CLI；不要把 dreamina 通用命令、国际版扩展或其他厂商 MCP 视为同一套接口。

操作前发现程序，读取版本、schema/帮助、认证状态与模型能力。有可用的 dreamina-canvas-cli Skill 时读取其相关操作协议；缺少时用 CLI 自带文档及官方资料，不自动装其他执行器。模型、时长、比例、分辨率、素材上限、引用字段都实时核对，不从本文猜旗标。

从实际返回结果确定画布链接，遵循用户浏览器偏好，尽量复用已有页面。先读现有节点再决定复用或新增，保留已有作品。按实际内容组织图片、主体和视频，避免为流程完整而增加无用节点。布局以可读、不遮挡、保留既有区块为目标。

运行前核对：参考素材可用；主体主辅图正确；正文角色与引用槽一致；上游连线存在；模式支持输入；素材展开数量未超限；节点规格与剧本一致。ID、占位符和引用语法来自当前 CLI 文档，不从别的项目的 @Image 或 API 字段类推。

“先审核”“只准备”“我来点击生成”意味着保存可检查草稿，不提交视频。图片和视频授权分别判断。实际生成按已有授权、服务端报价和批准规则执行，必要时取得平台要求的批准，不每个可逆编辑都重复询问。

操作结果不确定时先查同一次提交，避免重复生成或计费。持久化公开节点、任务和资源标识及创作选择，不保存令牌、签名下载链接或账号私密配置。身份、权限、积分或能力不匹配时保留恢复状态并说明具体阻碍，不换 ID 重复撞同一拒绝。

预生产交付包含画布链接、提示词、实际规格、角色映射、待确认事项和运行状态。区分只写方案、已保存、生成中、已完成；接口接受和 success 状态不能代替视觉检查。
