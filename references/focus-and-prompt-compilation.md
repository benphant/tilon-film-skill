# 聚焦与提示词编译

用于从简单场景写电影提示词，或把详细导演稿编译为模型输入。详细度服务于观众的注意力：同一个表情、一次接触或一种摄影关系可以写得很准，不必增加更多事件。

## 先找本镜重点

用一句话明确主体、观众正在等待的变化与结束落点。例如“旁观渡轮上的女子出神，直到她回头与镜头对视”；或“面碗稳定占据前景，宋代街景随送面脚步流过”。短镜头可先选一个视觉中心、一条主运动和一个落点来检查取舍；这是起点，群像、多焦点调度和蒙太奇有意图时可以扩展。

环境细节要承担作用：渡轮水光支持漂泊感，半开的窗解释碎发的运动，模糊乘客体现她身处人群；托盘的木纹、轻微汤纹和沿途棚影证明运动发生在同一个物理空间。背景人物可独立活动，但无须为每个路人新增一段戏。

## 三层细节

1. **必须保持的关系**：主体身份、关键造型、机位相对主体的位置、动作因果、核心道具数量、光源方向、时长与声音要求。优先写清。
2. **强化本镜的细节**：眼睛先动再转头、手指松开后的反应、掠过脸侧的水光、轻薄水汽。按场面选择少量，避免同时抢焦点。
3. **可删除的装饰**：同义情绪词重复、泛泛赞美画质、无关人群动作、不会影响画面的参数、覆盖整张表的否定词。删除后主镜意图仍应完整。

复杂接触、越轴、交接道具等易混动作需要精确先后和归属；简单凝视、步行或展示把细节集中在表演、构图和变化来源。不能为了缩短提示词删去关键反应，也不能为满足字段数量凭空加入事情。

## 从导演稿到提交正文

导演稿保留时间、人物、服化道、空间、摄影、光线、声音及终态，便于执行和审片。提交正文沿着观众实际看见的顺序组织：场景与主体 → 摄影关系 → 连续动作或明确切点 → 光影与声音 → 结束状态。必要的全局约束只说明一次；已经冻结且未变化的衣物、位置不要在每个节拍重复。

单镜可以用自然连贯段落，也可标出动作节拍；多镜保留每段时间与切点。计时分段不等于剪切。情绪用可演行为表达，例如视线停住、轻抿嘴唇、先移眼再转头；少用一串“深邃、忧郁、沉思”替代表演。摄影机靠近应说明要读到什么，固定机位也应明确它与主体、环境的关系。

补齐会造成歧义的空间事实：回头看镜头时，摄影机起初在哪一侧；窗边风从哪里来；固定太阳照在何处；托盘摄影机是否与碗共同运动。保护关键细节的景深与焦点，不让“极浅景深”虚掉所需证据。

画幅、秒数、分辨率属于生成配置。正文可复述视觉意图，但“4K”“电影级”“杰作”等词不会提高实际输出档位。电影感来自视线组织、景别变化、真实材质、光线方向、节奏和可读的表演，不以词数或形容词数量衡量。

## 场景输入与交付

只有一句场景时，先继承用户已给定的事实与风格，再补足使它可拍摄的最少假设。不要自动增加悲惨身世、陌生角色、旁白或新反转。时长、画幅等应用已有默认值可以使用并在说明中列出；不能把假设写成用户原要求。

交付可复制正文；需要时另附导演要点与假设。中英文版本应表达相同人物、时序、机位、光源及声音，不让翻译重新编剧情。引用图的真实绑定在执行层完成，未提供素材时不编造媒体 ID 或声称已锁定人物。

交付前检查：主次可辨；动作与对白装得进时长；机位能到达、视线能对上；光源固定且变化有原因；结尾完成本镜意图；没有用大段否定词掩盖互相矛盾的正向指令。提示词通过检查也不等于模型成片合格。
