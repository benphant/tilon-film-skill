# 聚焦提示词示例

下列是原创编译示例，展示如何保留表演与摄影关系。时长、画幅与造型是这两个例子的选择，不是所有项目的默认值；均未作为成片质量保证。

## 渡轮女子：10 秒连续镜头

导演意图：从旁观她的出神，到与她直接对视。表演推进和摄影推进共同服务这一变化。摄影机始终在她的右后侧，最后的回头有明确空间依据。

```text
10秒，16:9，写实电影质感，一个连续镜头。行驶中的渡轮舱内，一位年轻亚洲女子靠在半开的窗边，穿米色风衣，围着宽厚的格纹围巾。上身朝向窗外，头微侧，目光落在远处水面；嘴唇轻抿，肩膀放松。后排乘客柔化为安静的人影。

摄影机从她右后侧约两米处的中景开始，沿舱内通道缓慢靠近，始终留在同一侧。0–4秒看见窗边的她与船舱，4–7秒连续推近到脸与肩的近景；焦点从侧脸转到逐渐显露的近侧眼睛，推近在她转头前缓缓停住。她先移眼察觉身后的注视，再于7–9秒慢慢越过右肩转头，最后一秒直视镜头，神情克制，不微笑也不突然瞪眼。这个转身使近侧眼睛成为构图的中心，而非另切一个正面特写。

她面向的舷窗提供固定主光，水面反射在舱壁和她脸侧缓慢移动；半开窗的微风只吹动几缕碎发，短暂掠过脸颊，不遮住最后的眼神。保留自然皮肤纹理和少量手持呼吸，背景保持柔化，最后对视清晰。只听见低沉船机声、水声与衣料轻响。无对白、无旁白、无BGM、无字幕；镜头不中断，结束于她保持的目光。
```

## 托盘上的面：12 秒连续镜头

导演意图：固定的食物近景与流动街景形成反差。精度放在摄影机与托盘的关系、汤水惯性和沿途光线，不安排额外人物情节。

```text
12秒，16:9，写实宋代市井电影质感，一镜到底。送面人稳端深棕木托盘沿临河石板街步行，托盘上只有一碗清汤细面，少量葱花浮在汤面，一双竹筷放在右侧。摄影机固定在托盘前缘朝向碗，略高于碗沿，碗居中偏下、占画面宽约一半；整段保持碗的大小、位置与透视，焦点落在湿润面条与碗沿。双手端盘的局部留在边缘。

0–4秒沿河前行，桥与船篷在后方连续退开；4–8秒只作一次轻缓转向，进入紧邻河岸的市街，近处木柱与远处店铺呈现不同速度的视差。8–12秒继续穿过棚影并回到晨光，保持同一段步行和同一构图，结束时仍在送面。摄影机、托盘和碗共同起伏，汤水因脚步产生浅小波纹，逐渐回稳；面条仍浸在汤中，薄汽被行进气流轻轻带向一侧。

晨光始终从右后上方照来，棚影同时掠过碗、手与木盘，出棚后瓷沿和汤面恢复暖色反光。背景行人各自经过或停留，不看镜头，不遮挡碗。保留真实瓷釉、木纹和汤水质感，街景柔化但能辨认。只留脚步、远处街市与水声，无BGM、无字幕、无旁白。无剪切、变焦或绕碗运动；碗底保持接触托盘，筷子留在原位。
```
